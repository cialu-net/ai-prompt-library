# Writing

## Draft for an audience

```text
Write a [FORMAT] for [AUDIENCE] about [TOPIC]. The goal is [GOAL]; include [KEY POINTS]. Use a [TONE] tone and keep it under [LENGTH]. Do not invent facts; flag missing details.
```

## Edit for clarity

```text
Edit the following text for clarity and concision while preserving its meaning and voice. Return the revised version, followed by a short list of substantive changes or ambiguities: [TEXT]
```

## Turn notes into a concise summary

```text
Turn these notes into a concise summary for [AUDIENCE]: [NOTES]. Highlight the main points, decisions, open questions, and next steps where stated. Preserve names and dates accurately; label unclear ownership or deadlines instead of guessing. Keep it within [LENGTH].
```

## Adapt a message to an audience

```text
Adapt this message for [AUDIENCE] and [CHANNEL]: [TEXT]. Preserve the facts and intended action, use a [TONE] tone, and fit within [LENGTH]. Return the revised message and flag any wording that could be misunderstood or requires confirmation.
```
