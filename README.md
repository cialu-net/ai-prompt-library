# AI Prompt Library

A growing collection of reusable prompts for everyday work. Browse a category, copy a prompt, and replace the text in square brackets with your own context.

## Categories

- [Finance](prompts/finance.md) — compare scenarios and understand financial information
- [Coding](prompts/coding.md) — debug, review, and plan changes
- [Gaming](prompts/gaming.md) — build game systems and effects
- [Research](prompts/research.md) — investigate questions and assess evidence
- [Writing](prompts/writing.md) — draft and revise clear communication
- [Productivity](prompts/productivity.md) — make decisions and plan work

## Tips

Give the model relevant context, constraints, and examples. Ask it to identify uncertainty and check its output before acting on it. Avoid sharing passwords, sensitive personal data, or confidential information without appropriate safeguards. Financial prompts support exploration, not professional advice; verify figures and consult a qualified professional when appropriate.

## Contributing

Add a prompt to the closest category. Give it a descriptive heading, a short purpose, and a copyable prompt with placeholders. Keep examples general and remove private information.
